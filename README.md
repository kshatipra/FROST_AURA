# FROST Aura campaign site

Three pages, no build step:

- `index.html` - the campaign page.
- `why-it-matters.html` - the research page
- `film.html` - "The little things", the 35-second film on its own (good for sharing as a link)

## Put it on GitHub Pages

1. Upload the three `.html` files to the repository (Add file > Upload files > Commit).
2. Settings > Pages > "Deploy from a branch", branch `main`, folder `/ (root)`, Save.
3. A minute later it is live at `https://kshatipra.github.io/FROST_AURA/`.

GitHub Pages sites are public. For founders-only access, use a password-protected host (e.g. Netlify).
