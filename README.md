# FROST Aura campaign site

Two pages, no build step:

- `index.html` - the campaign page
- `why-it-matters.html` - the research page

## Put it on GitHub Pages

1. Create a new repository on GitHub (for example `frost-campaign`).
2. Upload `index.html` and `why-it-matters.html` (Add file > Upload files > Commit).
3. Go to Settings > Pages. Under "Build and deployment", pick "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/frost-campaign/`.

To keep it private for other founders only, use Netlify or Vercel with password protection, or keep the GitHub repo private (GitHub Pages on private repos needs a paid plan).

Fonts load from Google Fonts. Everything else is inside the two files.
